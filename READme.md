
Python Assignment – Part A

Topic: Dictionary in Python

Description

This assignment contains five Python programs based on dictionaries. It covers dictionary operations, nested dictionaries, comprehensions, grouping, sorting, searching and data management.

Q1. Student Database (Nested Dictionaries)

- Add a new student.
- Update subject marks.
- Delete a student.
- Display student records.
- Calculate average marks.
- Find the topper.
- Find the highest scorer in each subject.
- Display students scoring below 40.
- Group students according to grades.

Q2. Employee Database (Grouping and Aggregation)

- Add employee details.
- Update employee salary.
- Delete employee records.
- Search employees by ID.
- Calculate department-wise payroll and headcount.
- Find the highest-paid employee in each department.
- Sort employees by salary.
- Calculate a 10% salary raise using dictionary comprehension.
- Find the department with the highest average salary.

Q3. Library Record System

- Add books to the library.
- Issue books to members.
- Return issued books.
- Search for books.
- Find books by a particular author.
- Display members holding more than one book.
- Find unavailable books.
- Find books that have never been issued.

Q4. Word Frequency Counter

- Take a paragraph as input.
- Convert text into lowercase.
- Remove punctuation.
- Count word frequency.
- Display the top N words.
- Find words appearing exactly once.
- Invert the frequency dictionary.
- Group words according to their length.
- Search for a particular word.

Q5. Phone Directory

- Add new contacts.
- Add multiple phone numbers.
- Update email or city.
- Delete contacts.
- Search contacts by partial name or phone number.
- Perform reverse phone lookup.
- Group contacts according to city.
- Find contacts having multiple numbers.
- Display the complete directory alphabetically.

Python Concepts Used

1. Dictionaries

Sample Data

The programs use sample student, employee, book and contact records to demonstrate dictionary operations.

Conclusion

Through this assignment, I learned how to create, access, update and delete dictionary elements in Python. I also learned how to use dictionaries for real-life applications such as student management, employee management, library systems, word counting and phone directories.
