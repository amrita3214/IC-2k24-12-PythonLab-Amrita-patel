Python Lab 1

Program 1: Variable Practice

Aim: To understand variables and their data types.

Logic: Create variables of different data types such as string, integer, float, and Boolean. Print their values and data types.

Sample Output:

Name: Amrita <class 'str'>
Age: 20 <class 'int'>
Height: 5.4 <class 'float'>
Student: True <class 'bool'>

Program 2: Greeting

Aim: To take user input and display a greeting.

Logic: Accept the user's name, age, and city. Display the information using an f-string.

Sample Input:

Amrita
20
Indore

Sample Output:

My name is Amrita, I am 20 years old, and I live in Indore.

Program 3: Arithmetic Operations

Aim: To perform basic arithmetic operations.

Logic: Accept two numbers and calculate addition, subtraction, multiplication, division, and remainder.

Sample Input:

10
3

Sample Output:

Addition: 13.0
Subtraction: 7.0
Multiplication: 30.0
Division: 3.3333333333333335
Remainder: 1.0

Program 4: Celsius to Fahrenheit

Aim: To convert Celsius into Fahrenheit.

Logic: Take temperature in Celsius and apply the conversion formula.

Sample Input:

25

Sample Output:

Temperature in Fahrenheit: 77.0

Program 5: String Manipulation

Aim: To understand different string operations.

Logic: Accept a full name and perform uppercase, lowercase, reverse, length, title case, and capitalize operations.

Sample Input:

Amrita Patel

Sample Output:

Uppercase: AMRITA PATEL
Lowercase: amrita patel
Reversed: letaP atirmA
Length: 12
Title Case: Amrita Patel
Capitalized: Amrita patel

Program 6: Escape Sequences

Aim: To understand escape sequences in Python.

Logic: Use "\t" to create tab spaces and "\n" to create new lines. Display a simple shopping receipt.

Sample Output:

========== RECEIPT ==========
Item            Price
-----------------------------
Pen             Rs. 10
Book            Rs. 50
Bag             Rs. 200
-----------------------------
Total           Rs. 260
=============================

Thank you for shopping!
